# Sample channel fill: ClearCash

This folder shows how to fill the templates in `../guides/` for one fictional niche. It is **not** a live production channel.

Copy `../guides/` into your real channel folder, then replace placeholders using a fill sheet like this one (or start from these already-filled files and rewrite identity).

## Files in this sample

| File | Role |

| `Video Idea - Idea Guide.md` | Filled idea coach guide |

| `script-snippet.txt` | Tiny Custom-format script sample |

| `fill-sheet` (this README table) | Quick reference for every placeholder |

For Script bible / Production workflow / image prompts: copy from `../guides/` and apply the same fill sheet (search-replace each placeholder).

## Wire it in Higgsfilm

1. Create a real folder (not under `examples/`).
2. Copy filled guides + your art refs into that folder.
3. Settings → new channel profile → point Idea guide + Script bible at the filled `.md` files.
4. Paste visual bible fields from the style guide.
5. In image tools, choose the filled Custom / Expression guides and attach the character sheet + face refs.
